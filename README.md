# FUTURE_ML_02 - Support Ticket Classification

## 📌 Objective
Automatically classify customer support tickets 
and assign priority levels using NLP and ML.

## 🛠️ Tools Used
- Python, NLTK, Scikit-learn
- TF-IDF Vectorization
- Logistic Regression, Naive Bayes
- Matplotlib, Seaborn, WordCloud

## 📊 Dataset
Customer Support Ticket Dataset (Kaggle)

## 🔍 Key Features
- Text Cleaning & Tokenization
- Ticket Category Classification
- Priority Tagging (High/Medium/Low)
- Model Evaluation with Confusion Matrix
- Live Ticket Classification System

## 📈 Results
- Best Model selected between LR and Naive Bayes
- Real-time ticket classification with confidence score
